# 4.3 Task Configuration

Task configuration là quá trình thiết lập một task trước khi nó chạy. Gradle thực thi configuration code trong **configuration phase** — phase này xảy ra trước khi bất kỳ task action nào được execute.

Bạn dùng configuration block để set các property cho task, bao gồm cả việc khai báo input và output của nó.

## inputs / outputs

Gradle task thường xử lý dữ liệu. Chúng nhận **inputs** và tạo ra **outputs**.

Ví dụ, một compile task nhận source code file làm input và tạo ra compiled class file làm output.

Bạn phải khai báo inputs và outputs cho Gradle thông qua property `inputs` và `outputs` của task.

```groovy
task generateReport {
    // Define the input file
    inputs.file("src/data.txt")
    
    // Define the output file
    outputs.file("build/report.txt")

    doLast {
        println "Generating report..."
        // Code to read data.txt and write report.txt
    }
}
```

Khai báo inputs và outputs giúp Gradle hiểu được luồng dữ liệu trong project.

## incremental build

**Incremental build** là một tính năng mạnh của Gradle. Nó tiết kiệm thời gian bằng cách skip các task không cần chạy lại.

Gradle dùng `inputs` và `outputs` để quyết định có nên chạy một task hay không. Trước khi chạy, Gradle kiểm tra inputs và outputs của task đó.

Nếu inputs không thay đổi kể từ lần build trước, và outputs cũng không thay đổi, Gradle sẽ skip task đó và đánh dấu nó là `UP-TO-DATE`. Điều này giúp quá trình build nhanh hơn đáng kể.

Nếu bạn không khai báo inputs và outputs, task sẽ luôn chạy. Vì vậy, việc khai báo chúng đúng cách là rất quan trọng.
