# 5.2 Community Plugins

Community plugins được tạo bởi các developers hoặc công ty khác. Chúng thêm các tính năng mở rộng cho Gradle. Bạn có thể tìm chúng trên Gradle Plugin Portal. Để dùng một community plugin, bạn phải chỉ định ID và version của nó trong file `build.gradle`.

## Spring Boot plugin

Spring Boot plugin là một community plugin rất phổ biến. Nó giúp bạn build và run các Spring Boot applications dễ dàng.

Plugin này làm nhiều việc hữu ích. Thứ nhất, nó package application của bạn thành một file Jar hoặc War có thể execute. Thứ hai, nó cho phép bạn run application trực tiếp bằng một Gradle task đơn giản. Thứ ba, nó tích hợp chặt chẽ với Spring Boot's dependency management để kiểm soát các library versions.

Để dùng plugin này, bạn thêm ID của nó vào block `plugins`. Ví dụ:
```gradle
plugins {
    id 'org.springframework.boot' version '3.2.0'
}
```

## Shadow (fat jar)

Shadow plugin được dùng để tạo một "fat Jar". Một fat Jar là một file Jar duy nhất chứa application code và tất cả các dependencies cần thiết. Điều này giúp application của bạn rất dễ run và deploy ở bất kỳ đâu.

Thông thường, một file Jar tiêu chuẩn chỉ chứa code của bạn. Shadow plugin thay đổi điều này. Nó thu thập tất cả các files cần thiết từ các external libraries và đặt chúng vào trong một file Jar lớn.

Để dùng Shadow plugin, bạn thêm ID của nó. Ví dụ:
```gradle
plugins {
    id 'com.github.johnrengelman.shadow' version '8.1.1'
}
```

## Docker plugin

Có một số Docker plugins cho Gradle. Chúng giúp bạn build và publish Docker images. Một Docker image chứa toàn bộ application và mọi thứ cần thiết để run bên trong một container.

Các plugins này cho phép bạn build Docker images trực tiếp từ Gradle build. Một lựa chọn phổ biến hiện nay là Google Jib plugin. Jib đặc biệt vì nó build các Docker images được tối ưu hóa cho Java applications, và bạn thậm chí không cần viết một `Dockerfile`.

Ví dụ, để dùng Jib plugin:
```gradle
plugins {
    id 'com.google.cloud.tools.jib' version '3.4.0'
}
```
