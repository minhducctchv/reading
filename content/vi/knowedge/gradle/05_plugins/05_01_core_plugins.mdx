# 5.1 Core Plugins

Gradle có nhiều built-in plugins. Chúng được gọi là core plugins. Bạn không cần download chúng. Chúng sẵn sàng để dùng. Core plugins giúp bạn build các loại project phổ biến.

## java

Plugin `java` rất phổ biến. Nó thêm Java compilation vào project của bạn. Nó cũng thêm các tính năng testing và bundling.

Khi bạn apply plugin này, Gradle biết cách làm việc với Java source code. Nó tạo ra các standard tasks cho project. Một số tasks quan trọng là `compileJava`, `classes`, `test`, và `jar`.

Nó cũng thiết lập các standard source folders. Java code chính của bạn nên đặt trong `src/main/java`. Test code nên đặt trong `src/test/java`.

## application

Plugin `application` giúp bạn build các executable JVM applications. Nó hoạt động cùng với plugin `java`.

Plugin này giúp bạn dễ dàng run application ở local. Nó cung cấp task `run` để khởi động chương trình. Bạn phải cho Gradle biết class nào chứa method `main`.

Nó cũng có thể package application để distribution. Nó tạo ra các file zip hoặc tar. Các file này chứa compiled code và tất cả các thư viện cần thiết. Nó cũng tạo start scripts cho Linux và Windows.

## war

Plugin `war` dành cho các Java web applications. Nó extends plugin `java`. Nó giúp bạn tạo các file WAR (Web Application Archive).

Một file WAR chứa các compiled classes, web pages, và configuration files. Bạn có thể deploy file này lên một web server như Tomcat.

Plugin này thêm task `war` để build archive. Nó mong đợi các file web page của bạn nằm trong một folder cụ thể. Mặc định, nó tìm trong `src/main/webapp`.
