# 1.2 Comparison với Maven / Ant

Ant, Maven, và Gradle là các build tool phổ biến. Developer dùng chúng cho các Java project. Các tool này giúp compile code, chạy test, và tạo ra ứng dụng có thể chạy được. Mỗi tool có lịch sử và đặc điểm khác nhau.

## Apache Ant

Apache Ant là tool cũ nhất. Nó được release năm 2000.

Ant dùng XML file cho build script. Nó không ép buộc một cấu trúc thư mục cụ thể lên project của bạn. Điều này cho bạn rất nhiều sự tự do. Tuy nhiên, bạn phải viết hướng dẫn chi tiết cho từng bước của quá trình build.

Bản thân Ant không thể tự download các external library. Để quản lý dependency tự động, bạn phải dùng thêm một tool gọi là Apache Ivy.

## Apache Maven

Apache Maven được release năm 2004. Nó được tạo ra để cải thiện Ant.

Maven cũng dùng XML file. File chính được gọi là `pom.xml`. Maven giới thiệu một khái niệm gọi là "convention over configuration." Nghĩa là Maven kỳ vọng project của bạn có một cấu trúc nhất định. Nếu bạn theo standard layout của Maven, build script của bạn có thể rất ngắn gọn.

Maven có dependency management rất tốt. Bạn chỉ cần liệt kê các library cần dùng. Maven tự động download chúng từ internet. Nhược điểm chính là Maven khá strict. Rất khó để thay đổi quá trình build mặc định.

## Gradle

Gradle là tool mới nhất trong ba tool. Nó được release năm 2007.

Gradle không dùng XML. Thay vào đó, nó dùng ngôn ngữ lập trình như Groovy hoặc Kotlin. Điều này khiến build script dễ đọc và viết hơn nhiều.

Gradle kết hợp các tính năng tốt nhất của Ant và Maven. Nó cung cấp dependency management mạnh mẽ như Maven. Đồng thời mang lại sự linh hoạt cao như Ant. Vì sử dụng ngôn ngữ lập trình thực sự, bạn có thể viết custom build logic một cách dễ dàng.

Hơn nữa, Gradle rất nhanh. Nó sử dụng các tính năng thông minh như incremental build và build cache. Điều này có nghĩa là nó chỉ rebuild các phần code đã thay đổi. Hiện nay, Gradle là build tool chính thức cho Android development.

## Summary

Dưới đây là bảng so sánh nhanh ba tool:

*   **Script Format:** Ant và Maven dùng XML. Gradle dùng Groovy hoặc Kotlin.
*   **Flexibility:** Ant và Gradle rất linh hoạt. Maven strict hơn.
*   **Performance:** Gradle là tool nhanh nhất cho các large project.
*   **Best Use Case:** Ant dùng cho các legacy project. Maven phù hợp cho các standard Java application. Gradle tốt nhất cho các complex project và Android app.
