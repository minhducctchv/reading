# 5.4 Plugin Management

## What is pluginManagement?

`pluginManagement` is a special block in Gradle. 
You write it inside the `settings.gradle` or `settings.gradle.kts` file. 
It must be the very first block in the file.
It tells Gradle where to find and how to load plugins.

## Setting Plugin Repositories

By default, Gradle looks for plugins in the Gradle Plugin Portal. 
Sometimes, plugins are not there. 
You can tell Gradle to look in other places. 
You use the `repositories` block to do this.

```kotlin
// settings.gradle.kts
pluginManagement {
    repositories {
        gradlePluginPortal()
        mavenCentral()
        google()
    }
}
```

This code tells Gradle to check three places. 
It will search the Plugin Portal, Maven Central, and Google.

## Managing Plugin Versions

You can set a plugin version in one place. 
This is very useful for large projects with many modules. 
You set the version inside the `plugins` block.

```kotlin
// settings.gradle.kts
pluginManagement {
    plugins {
        id("org.springframework.boot") version "3.1.2"
    }
}
```

Now, all modules will use this specific version. 
You do not need to write the version again in your `build.gradle.kts` files.

```kotlin
// build.gradle.kts
plugins {
    id("org.springframework.boot") // No version needed here
}
```

This keeps your project clean and consistent.
