# 1.3 Installation

To use Gradle, you need to install it. There are two main ways to do this. You can install it on your computer. This is called a local install. Or, you can use the Gradle Wrapper. The Gradle Wrapper is the recommended way.

## Local install

A local install means you download Gradle and put it on your computer. You also add it to your system path. This lets you run the `gradle` command from anywhere.

To install Gradle locally, you must have Java installed first. After that, you can download the Gradle file from their official website. Then, you extract the file and set up the Environment Variables.

This method is good if you want to use the same Gradle version for many projects. However, it can cause problems if different projects need different Gradle versions.

## Gradle Wrapper (gradlew)

The Gradle Wrapper is a small script. It comes with your project. The script is called `gradlew` on Linux and macOS. It is called `gradlew.bat` on Windows.

When you run the wrapper, it checks if you have the right Gradle version. If you do not have it, the wrapper downloads it for you. Then, it runs your build.

This is the best way to use Gradle. It means everyone uses the exact same Gradle version for the project. You do not need to install Gradle manually. You only need to have Java installed. The wrapper makes it very easy to start working on a project together.
