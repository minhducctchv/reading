# 1.6 Basic Commands

Gradle provides many commands to work with your project. However, you will use a few commands very often. Here are the most fundamental commands you need to know.

## gradle build

The `gradle build` command is the most important command. It compiles your code, runs your tests, and creates the final output file (like a JAR or WAR file). 

When you run this command, Gradle executes many small tasks inside. It checks if any code has changed. It only rebuilds the parts that are necessary. This makes the build process very fast.

## gradle clean

The `gradle clean` command removes the `build` directory. This directory contains all the files that Gradle created during previous builds. 

Sometimes, your project might have old or broken files. Running `gradle clean` forces Gradle to delete everything it made. The next time you build, Gradle will create everything fresh from your source code.

## gradle tasks

The `gradle tasks` command helps you discover what your project can do. It lists all the available tasks you can run. 

This command groups tasks by category. For example, it shows "Build tasks" or "Verification tasks". It is a great way to learn about the features of your Gradle build. It shows you the commands without actually running them.
