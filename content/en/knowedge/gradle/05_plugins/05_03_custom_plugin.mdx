# 5.3 Custom Plugins

Sometimes, you need to use the same build logic many times. You can put this logic into a custom plugin. A custom plugin helps you reuse code easily. You can write custom plugins in Groovy, Kotlin, or Java.

There are two main ways to make a custom plugin.

## buildSrc Directory

The first way is using the `buildSrc` directory. You create this folder at the root of your project.

When you run Gradle, it automatically finds the `buildSrc` folder. It compiles the code inside. Then, you can use the plugin in your project's build scripts.

**Benefits:**
- It is very easy and fast to set up.
- It makes your main build script much cleaner.

**Limits:**
- You can only use this plugin inside this one project. You cannot share it with other projects.
- If you change code inside `buildSrc`, Gradle might need to rebuild the whole project.

## Standalone Plugin

The second way is making a standalone plugin. This is a completely separate Gradle project.

When you build a standalone plugin, it creates a JAR file. You can publish this JAR file to an online repository. Examples are Maven Central or the Gradle Plugin Portal.

**Benefits:**
- You can use this plugin in many different projects.
- You can share it with other developers.

**Limits:**
- It takes more time to set up.
- You must manage versions and publish the plugin yourself.
