# 5.1 Core Plugins

Gradle has many built-in plugins. These are called core plugins. You do not need to download them. They are ready to use. Core plugins help you build common types of projects.

## java

The `java` plugin is very popular. It adds Java compilation to your project. It also adds testing and bundling features.

When you apply this plugin, Gradle knows how to work with Java source code. It creates standard tasks for your project. Some important tasks are `compileJava`, `classes`, `test`, and `jar`.

It also sets up standard source folders. Your main Java code should go in `src/main/java`. Your test code should go in `src/test/java`.

## application

The `application` plugin helps you build executable JVM applications. It works together with the `java` plugin.

This plugin makes it easy to run your application locally. It provides a `run` task to start your program. You must tell Gradle which class contains your `main` method.

It can also package your application for distribution. It creates zip or tar files. These files contain your compiled code and all required libraries. It also creates start scripts for Linux and Windows.

## war

The `war` plugin is for Java web applications. It extends the `java` plugin. It helps you create WAR (Web Application Archive) files.

A WAR file contains your compiled classes, web pages, and configuration files. You can deploy this file to a web server like Tomcat.

This plugin adds a `war` task to build the archive. It expects your web page files to be in a specific folder. By default, it looks in `src/main/webapp`.
