# 4.2 Custom Tasks

Sometimes, the built-in tasks are not enough. You might need to do something special for your project. Gradle allows you to create custom tasks. You can write custom tasks using Groovy or Kotlin.

## DefaultTask

`DefaultTask` is the base class for all tasks in Gradle. When you want to create a completely new task, you should extend `DefaultTask`. This allows you to add your own code. Gradle will run your code when you execute the task.

When you create a custom task class, you use the `@TaskAction` annotation. This annotation tells Gradle which method to run.

```kotlin
// Example of a custom task extending DefaultTask
abstract class MyCustomGreetingTask : DefaultTask() {
    @TaskAction
    fun greet() {
        println("Hello from my custom task!")
    }
}

// Registering the custom task
tasks.register<MyCustomGreetingTask>("myGreeting")
```

## Task Types

Gradle provides many common task types ready to use. These are also called "built-in task types". They extend `DefaultTask` and add specific features.

For example, you do not need to write a new task from scratch to copy files. You can just use the `Copy` task type.

```kotlin
// Example of using the built-in Copy task type
tasks.register<Copy>("copyReports") {
    from("build/reports")
    into("build/backup")
}
```

Some common built-in task types include:
- **Copy**: Copies files from one place to another.
- **Delete**: Deletes files or directories.
- **Zip**: Creates a ZIP file.
- **Exec**: Runs a command-line program.

Using existing task types saves you time. You only need to configure them. If no built-in type fits your needs, you can easily create a custom one by extending `DefaultTask`.
