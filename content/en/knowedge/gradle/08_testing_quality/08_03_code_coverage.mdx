# 8.3 Code Coverage (JaCoCo)

### Overview
Code coverage measures how much of your source code is tested by your automated tests. It helps you find untested parts of your application. In the Java ecosystem, JaCoCo is the standard tool for measuring code coverage.

### Applying the JaCoCo Plugin
Gradle has built-in support for JaCoCo. You can add it to your project by applying the JaCoCo plugin in your `build.gradle` file.

```groovy
plugins {
    id 'java'
    id 'jacoco'
}
```

Once you apply the plugin, Gradle automatically starts collecting coverage data when you run your tests.

### Generating Coverage Reports
By default, running tests only creates binary data files. You need a human-readable report to see the coverage results. You can generate HTML or XML reports using the `jacocoTestReport` task.

```bash
./gradlew test jacocoTestReport
```

After running this command, you can find the HTML report in the `build/reports/jacoco/test/html` directory. Open the `index.html` file in your browser to view the coverage details.

### Configuring the Report Task
You can configure the `jacocoTestReport` task to control which report formats are generated. You can also specify which directories to include or exclude.

```groovy
jacocoTestReport {
    dependsOn test // Ensure tests run before generating the report

    reports {
        xml.required = true
        csv.required = false
        html.required = true
    }
}
```

### Enforcing Coverage Rules
You can enforce minimum code coverage standards using the `jacocoTestCoverageVerification` task. If the code coverage falls below your defined limits, the build will fail. This is very useful in CI/CD pipelines to maintain code quality.

```groovy
jacocoTestCoverageVerification {
    violationRules {
        rule {
            limit {
                minimum = 0.80 // Require 80% coverage
            }
        }
    }
}
```

To run this verification, use the following command:

```bash
./gradlew jacocoTestCoverageVerification
```

You can also make the `check` task depend on this verification so it runs automatically with your build process.

```groovy
check.dependsOn jacocoTestCoverageVerification
```
