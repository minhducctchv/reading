The process and environment for `producing` output.

Used to extend Gradle's `capabilities`.

Many developers will `interact` with Gradle for the first time through an existing project.

The `presence` of the gradlew and gradlew.bat files in the root directory of a project is a clear indicator that Gradle is used.

Gradle can be automatically `invoked` when you build, clean or run your app in IDE.

`Consult` the manual for the IDE of your choice to learn more about how Gradle can be used and configured.

Most projects do not use the installed of Gradle `but rather` the Gradle Wrapper.

Gradle can be invoked in the Command Line `once installed`.

Wrapper script invokes a declared version of Gradle, `downloading it beforehand` if necessary.

`Provisions` the same version of Gradle for different users and environments.
